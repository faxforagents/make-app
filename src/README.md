# Fax for Agents

Send faxes and read received ones through the [Fax for Agents](https://faxforagents.com) API. Connect with an API key from [app.faxforagents.com](https://app.faxforagents.com). A test key (ffa_test_) reaches the sandbox only and costs nothing. A live key (ffa_live_) reaches the carrier and spends the prepaid wallet.

Four modules: Send a Fax, Get a Fax Status, List Received Faxes and Make an API Call. Send a Fax takes text or Markdown to a number, with an optional cover sheet.

A live send needs a human approval bound to the exact quote, or a policy the account owner wrote outside Make. When the quote says so, the module stops with the quote id and nothing is sent. A person approves it in the dashboard and the approval id goes into the module.

The price card is effective from 2026-10-28. $0.039 per page sent, $0.019 per page received. $2 per number per month, $19 per month for the Agent workspace. Sandbox pages cost 0.

Documentation: https://faxforagents.com/docs/api/ Support: hello@faxforagents.com
